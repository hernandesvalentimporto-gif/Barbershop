# Correção da abertura — versão de teste 1.0.1

O usuário relatou que a versão 1.0.0 mostrava a logo e fechava. Foi encontrado um defeito concreto na navegação: após a restauração de sessão sem usuário, o layout das abas devolvia um redirecionamento para `/`, inclusive quando já estava na própria raiz. A nova regra redireciona somente rotas protegidas e permite renderizar o login. Há testes de regressão para as representações de raiz `index`, `(tabs)` e segmento ausente, preservando as permissões por perfil. Foi incluída uma tela de recuperação para erros JavaScript.

O APK 1.0.1 mantém o pacote space.manus.barberhp.t054228665129522 e usa versionCode 2. A assinatura V2 foi comparada com a do APK anterior e é igual, permitindo atualização. A build inclui ARM64 e x86_64, para celular e emulador, respectivamente.

A compilação do candidato foi concluída no GitHub Actions 41859865106. No teste em Android 15, a tela de login do aplicativo abriu, mas uma janela de ANR do Pixel Launcher, não do Barber Shop, impediu a leitura automatizada da tela. Foi reutilizado o MESMO APK, sem recompilação, em um emulador Android ATD API 30 (Android 11), com menos serviços de sistema. O reteste 41867691601 passou: instalação, abertura a frio, identificação de Entrar/E-mail, permanência do processo e reabertura. O XML de acessibilidade confirmou a tela de login. A captura gráfica do ATD ficou preta, portanto não é usada como comprovação visual; a captura anterior em Android 15 mostrava o login sob um diálogo de ANR do Pixel Launcher. Nenhum login ou POST de produção foi executado.
